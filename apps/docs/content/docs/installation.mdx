## Quick start

Render the content once with `<Floaty>`, and place a `<FloatyAnchor>` with the same
`floatyId` wherever it should appear. This complete example moves a counter between the
main area and a sidebar:

<include>../../components/examples/quick-start.tsx#example</include>

<Preview>
  <QuickStart />
</Preview>

<Callout title="Where to put Floaty">
  Render `<Floaty>` above everything that switches, for example in your app shell or root
  layout. If it unmounts, its content does too.
</Callout>
