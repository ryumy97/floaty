---
title: Typed channels
description: Bind the components and hooks to one id and one state type.
---

We can create a typed channel with `createFloaty<S>(floatyId)`. 
It contains components and hooks that shares the same state.


```tsx title="player.ts"
import { createFloaty } from '@ryumy97/floaty-react';

export const player = createFloaty<{ mode: 'full' | 'mini' }>('player');
```

```tsx title="App.tsx"
<player.Floaty>{(state) => <Player mode={state?.mode ?? 'full'} />}</player.Floaty>

<player.FloatyAnchor state={{ mode: 'mini' }} />
<player.FloatyAnchor state={{ mode: 'tiny' }} /> {/* type error */}
```

```tsx title="StatusBar.tsx"
function StatusBar() {
  const { hasAnchor, state } = player.useFloaty();
  return hasAnchor ? <span>{state?.mode}</span> : null;
}
```

Using typed channels, we can avoid having to provide id to the components and hooks all the time.
We can create a channel and reuse it in multiple places.

The channel has `floatyId`, `Floaty`, `FloatyAnchor`, `useFloaty`, `useFloatyState` and `useFloatyTransition`. 
They take the same props and return the same values as the unbound API.
