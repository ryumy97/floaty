`transition` is set globally with `configureFloaty` or per `<Floaty>`.

```tsx
configureFloaty({ transition: { type: 'spring', duration: 400, bounce: 0.2 } });
<Floaty floatyId="counter" transition={{ type: 'spring', duration: 400, bounce: 0.2 }}>
  <Counter />
</Floaty>
```

These can be one of the following:

```ts
false                                                     // snap
{ duration?: 300, easing?: 'ease-in-out' }                // easing: any CSS easing
{ type: 'spring', duration: 400, bounce?: 0 }             // spring, visual attributes
{ type: 'spring', stiffness: 300, damping: 25, mass?: 1 } // spring, physical attributes
```

## Try it

Tune a spring or an easing curve and press **Play**. The graph plots progress (0 to 1) over
time; the dashed line is `linear` with the same duration, and the lanes below race the two.

## Easing

Any CSS easing string works (`ease-in-out`, `cubic-bezier(...)`, `linear(...)`). Objects
without `type: 'spring'` are easing transitions; missing fields come from the global easing
default (or `{ duration: 300, easing: 'ease-in-out' }` if the global default is a spring).

## Springs

- **Visual:** `duration` is the perceptual duration in ms (the spring's period). `bounce`
  ranges from `-1` to `1`: `0` settles without overshoot, positive values bounce, negative
  values are overdamped. The tail may run slightly past `duration`.
- **Physical:** `stiffness`, `damping` and `mass` of a damped harmonic oscillator, with time
  in seconds.
- **`bounceSize`:** `false` (default) animates width and height with the same spring
  critically damped, so the box never overshoots its size. Pass spring attributes to give
  the size its own spring, for example
  `{ type: 'spring', duration: 400, bounce: 0.3, bounceSize: { duration: 400, bounce: 0.1 } }`.

Interruptions keep momentum with springs: a new anchor or a layout shift mid-flight
continues from the current position and velocity.

## When content animates

- Switching anchors animates. So does the active anchor moving or resizing, unless
  `animateLayoutChanges={false}`.
- `prefers-reduced-motion: reduce` turns every transition into a snap.
