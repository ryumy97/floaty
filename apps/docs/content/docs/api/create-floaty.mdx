---
title: createFloaty
description: Components and hooks bound to one id and one state type.
---

```ts
function createFloaty<S>(floatyId: string): FloatyChannel<S>;
```

Returns:

| Field | Equivalent to |
| --- | --- |
| `floatyId` | The bound id |
| `Floaty` | `<Floaty<S> floatyId={floatyId}>` |
| `FloatyAnchor` | `<FloatyAnchor<S> floatyId={floatyId}>` (forwards `ref`) |
| `useFloaty()` | `useFloaty<S>(floatyId)` |
| `useFloatyState()` | `useFloatyState<S>()`, but throws inside another id's content |
| `useFloatyTransition()` | `useFloatyTransition<S>()`, but throws inside another id's content |

Call it once at module scope. See [Typed channels](/docs/guides/typed-channels).
